## 🎯 Answer Common Questions

**Q: Is this real-time?**
A: Yes! The demo simulates real-time recognition. When connected to the ML backend, it will process frames in real-time.

**Q: How many gestures does it recognize?**
A: Currently, the demo shows 7 sample gestures. The production system can be scaled to recognize thousands of signs.

**Q: Works offline?**
A: Yes, this frontend works offline. Backend API can be in the cloud or on-premise.

**Q: Can it work on mobile?**
A: Yes! The UI is fully responsive. Mobile app support is in our future roadmap.

**Q: What about regional sign languages?**
A: Currently, it's designed for general gestures. Regional sign language support is planned for future versions.
