How It Works

Webcam Input

Real-time video feed captures sign language gestures from the webcam

Preprocessing

Frame normalization and background filtering for better accuracy

Feature Extraction

Extract hand landmarks and skeleton points using pose estimation

CNN Classification

Neural network classifies gesture and outputs prediction

Text Output
